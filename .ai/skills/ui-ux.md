# UI/UX & Npontu Design Skill

> **Platform**: UEW Innovation Hub Enterprise  
> **Domain**: Ergonomics, Visual Hierarchy, and Institutional Aesthetics

---

## 1. Visual Hierarchy
- **Header**: Institutional UEW Crest, project title, global search bar (`Cmd/Ctrl + K`), user profile with role badge, and dark/light mode toggle.
- **Navigation Sidebar**: High-contrast deep navy (`#0a1b4d`) with royal blue active state indicators and collapsible icon mode.
- **Cockpit Canvas**: Clean off-white canvas (`bg-slate-50 dark:bg-slate-900`) with high-density data tables and glassmorphic telemetry cards.
- **Typography**: Inter for UI labels, JetBrains Mono for metrics and statistics.

---

## 2. Micro-Interactions
- Subtle scale effect on button press (`active:scale-[0.98]`).
- Hover glow on status badges and KPI cards.
- Smooth transitions on modal overlays and slide-over drawers (`transition-all duration-200 ease-out`).
- Skeleton loaders during data fetch or page transition states.
