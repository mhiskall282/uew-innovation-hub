# Feature guides

> **Audience:** Members of the public and new staff · **Last verified:** 2026-11-30 against commit `9f3bdee`
> **Related:** [User guide home](../getting-started.md), [Step-by-step workflows](../step-by-step-workflows.md), [User FAQ](../user-faq.md), [Documentation home](../../README.md)

Each guide in this folder explains one feature for non-technical readers: what it does, who can use it, where to find it, the steps, the result you should see, the errors you may meet and how to fix them.

## How each guide is laid out

1. A short summary of the feature.
2. **What, why, who, where** in four bullet points.
3. Numbered steps with the expected result.
4. A table of messages and fixes. The messages are copied from the validation rules and controllers, so they match what you see on screen.

## Conventions

- Button and menu names are in **bold**, exactly as shown on screen.
- Addresses such as `/contact` are paths on the Hub site. Add the site's web address in front.
- "Staff" means anyone whose role is not Member. See [User roles and permissions](../user-roles-and-permissions.md).
- No screenshots are included yet. The plan is in [Screenshot plan](../screenshot-plan.md).
