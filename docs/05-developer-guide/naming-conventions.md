# Naming Conventions

> **Audience:** Developers · **Last verified:** 2026-11-30 against commit `9f3bdee`
> **Related:** [coding-standards](coding-standards.md), [project-structure](project-structure.md), [database-development](database-development.md)

Names used in the code base, with a real example of each. Follow Laravel defaults unless this page says otherwise.

## PHP

| Thing | Convention | Examples |
| --- | --- | --- |
| Model | Singular `PascalCase` in `app/Models/` | `Album`, `ProgramApplication`, `ProgressReport` |
| Table | Plural `snake_case` | `albums`, `album_photos`, `program_applications`, `progress_reports`, `activity_logs` |
| Foreign key | `<singular>_id`; user references often `created_by` | `program_id`, `cover_photo_id`, `created_by` |
| Controller | `<Thing>Controller` in a folder by area: `Site`, `Portal`, `Workspace`, `Auth`, `Api/V1` | `Workspace\AlbumController` |
| FormRequest | `<Thing>Request` or `Store<Thing>Request` / `Update<Thing>Request` | `PostRequest`, `StoreUserRequest` |
| Policy | `<Model>Policy` in `app/Policies/` | `AlbumPolicy` |
| Service | `<Domain>Service` or a noun, `final class`, in `app/Services/` | `GalleryService`, `AuditLogger`, `DocumentStorage` |
| Enum | Singular `PascalCase` noun, string-backed, cases in `PascalCase`, values in `snake_case` | `Role::SuperAdmin = 'super_admin'`, `ProjectStatus::Active = 'active'` |
| Permission value | `<area>.<verb>` in lower case | `projects.manage`, `content.publish`, `audit.view` |
| Permission case | `<Area><Verb>` | `ProjectsManage`, `ContentPublish` |
| Model trait | Descriptive, in `app/Models/Concerns/` | `HasUniqueSlug`, `Searchable` |
| Mailable | `<Thing>Mail` | `TemplatedMail` |
| Artisan command | `hub:<verb>-<noun>` | `hub:create-admin`, `hub:import-documents` |
| Class constants | `UPPER_SNAKE` | `GalleryService::MAX_MEGAPIXELS`, `AlbumController::MAX_FILES` |
| Methods | `camelCase`; scopes `scope<Name>` | `scopePublished`, `latestEvents` |
| Factory | `<Model>Factory`, with state methods named for the state | `UserFactory::role()`, `admin()`, `inactive()`, `member()` |

## Routes

| Area | URI prefix | Name prefix | File |
| --- | --- | --- | --- |
| Public website | `/` | `site.` | `routes/web.php` |
| Member portal | `/portal` | `portal.` | `routes/web.php` |
| Staff workspace | `/workspace` | `workspace.` | `routes/web.php` |
| Open data API | `/api/v1` | `api.v1.` | `routes/api.php` |

Route names are `<area>.<resource>.<action>` (`workspace.albums.edit`, `portal.applications.messages.store`). Generate URLs with `route('name')`. Do not hard-code paths. URIs use lower-case kebab-case (`progress-reports`, `password-reset`).

## Views and components

| Thing | Convention | Example |
| --- | --- | --- |
| Blade view | Lower-case kebab-case file, folder per feature | `resources/views/workspace/progress-reports/show.blade.php` |
| View name | Dot notation | `view('workspace.albums.index')` |
| Component | `components/ui/<name>.blade.php`, used as `<x-ui.<name>>` | `<x-ui.button>`, `<x-ui.empty>` |
| Layout | `components/layouts/<name>.blade.php`, used as `<x-layouts.<name>>` | `<x-layouts.workspace>` |
| Partial (not a component) | Leading underscore | `reports/_details.blade.php` |
| Slots | Named with `<x-slot:name>` | `<x-slot:actions>` |

## Database

| Thing | Convention | Example |
| --- | --- | --- |
| Migration file | `YYYY_MM_DD_NNNNNN_<description>.php`, sequence number per day | `2026_11_30_000001_create_gallery_tables.php` |
| Booleans | `is_<adjective>` | `is_published`, `is_featured`, `is_active` |
| Timestamps | `<event>_at` | `published_at`, `email_verified_at` |
| Enum columns | String column holding the enum value | `users.role` |
| Slugs | `slug`, unique, generated by `HasUniqueSlug` | `albums.slug` |

Schema detail is in `../07-database/tables-and-columns.md`.

## Tests

| Thing | Convention | Example |
| --- | --- | --- |
| PHPUnit class | `<Subject>Test`, namespace follows the folder | `Tests\Feature\Workspace\PrivilegesTest` |
| Test method | `test_<snake_case_behaviour>` | `test_every_state_changing_workspace_route_enforces_its_permission` |
| Helpers | Private methods at the bottom of the class | `GalleryTest::album()`, `jpeg()` |
| Shared helpers | `tests/TestCase.php` | `staff()`, `signInAs()`, `pdf()` |
| Playwright spec | `<topic>.spec.ts` in `tests/e2e/` | `journeys.spec.ts`, `a11y.spec.ts`, `responsive.spec.ts` |

## JavaScript, CSS and assets

- JS files are ES modules in `resources/js/`. `resources/js/app.js` imports the fonts and starts Alpine (`window.Alpine = Alpine; Alpine.start()`). It registers no named Alpine components; interactions use inline `x-data` in Blade.
- Design tokens use the `--color-uew-*` pattern in `@theme` (`resources/css/app.css`), which gives utilities such as `bg-uew-navy`.
- Images for the site are in `public/images/`. Photographs by third parties are listed with credits in `app/Support/Photos.php`.

## Language and spelling

User-facing text and documentation use British spelling. Code uses the terms in the glossary: the UI says "programme", the code says `program`; the table is `programs`, the enum is `ProgramType`.
